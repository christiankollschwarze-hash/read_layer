## DIE ARCHITEKTURWENDE: LLM-Regie RAUS, drei REGLER REIN (Stage 56)

### Das Problem (warum ueberhaupt)
Die bisherige buchspezifische Regie liess ein LLM aus `style` (tone/register/notes)
einen FREI FORMULIERTEN Regie-Satz schreiben (Jekyll z.B. "suspenseful, ominous").
Das war UNKONTROLLIERBAR:
- Das Modell dachte sich seinen eigenen Rahmen aus UND fuehrte ihn aus -> beide
  Rollen (Regisseur + Vorleser) in einer Hand.
- Im DEUTSCHEN erzeugte das einen systematischen "Substantiv-Tick": jedes
  Substantiv wurde auffaellig betont. Grausig, nicht reproduzierbar, nicht greifbar.
- CK-O-Ton: "diese blumige Regie-Anweisung treibt uns in den Wahnsinn."

### Zwischenschritt (verworfen/ueberholt): Komoedianten-Schutz
Erst gebaut: eine feste "Zurueckhaltungs-Klausel" (_RESTRAINT_DEFAULT), an jede
Regie angehaengt -- per A/B-Test (`tts_ab_emphasis.py`) bestaetigt ("ab B ganz klar",
"betont noch, aber nicht peinlich"). ABER: sie zielt auf THEATRALIK, nicht auf den
Substantiv-Tick. Wurde daher von der Regler-Loesung ABGELOEST (die Betonungs-Achse
auf "niedrig" ist jetzt das Gegenmittel). Historie, nicht mehr aktiv in Stage 56.

### Die Loesung (entschieden + gebaut)
Drei deterministische REGLER auf WERKEBENE in `book.json`:
```
"audio_regler": { "betonung": 1-10, "emotion": 1-10, "tempo": 1-10 }
```
- Mechanik-ehrlich: Gemini-TTS hat KEINE Parameter. Die Regler sind eine UI-Schicht,
  die in feste Klartext-Formulierungen uebersetzt wird. Je Achse 3 STUFEN
  (niedrig 1-3 / mittel 4-7 / hoch 8-10), "mittel" = neutral (keine Sonderanweisung).
  Zehn Stufen suggerieren eine Feinheit, die das Modell NICHT hoert -> bewusst nur 3.
- betonung niedrig = "even, level word stress; do not emphasize nouns ..." = das
  direkte Gegenmittel gegen den deutschen Substantiv-Tick.
- Fehlt `audio_regler` -> {5,5,5} = neutraler, ruhiger Erzaehler. Das LLM-Wuerfeln
  ist damit GANZ RAUS; kein Werk klingt mehr "suspenseful", weil ein Modell sich
  das ausdachte.
- Rollen sauber getrennt: Mensch SETZT den Rahmen (Regler), Gemini FUEHRT nur noch
  aus (Feinprosodie im Satz). Gemini = Vorleser, nicht mehr Regisseur.
- Entscheidung pro WERK (nicht pro Sprachfassung) -- bewusst, um Komplexitaet zu
  vermeiden. Falls das Ohr zeigt, dass DE andere Werte als EN braucht, kann die
  Achse spaeter pro Fassung nachgezogen werden (Datenmodell vertraegt es).

### BEWIESEN
Sleepy Hollow DE mit `--betonung 2 --emotion 4 --tempo` (leicht erhoeht): der
Substantiv-Tick ist WEG, "jetzt passt es" (CK). Erstes Werk, an dem die Regler
greifen.

## TTS-LIMIT-MODELL (geklaert, wichtig fuer Skalierung)
Frage war: "ein Werk pro Tag?" + "bringt Bündeln Faktor 20?"
- Belege aus der Cloud Console (Projekt readlayercloud):
  - **Cloud Text-to-Speech API**: alle Limits "...requests per minute" (z.B. 1.000/min),
    durchweg REQUEST-basiert, **anpassbar**. Kein Zeichen-/Tagestopf.
  - **Agent Platform API (= Vertex/aiplatform, dort laeuft Charon)**: ZWEI Toepfe
    gleichzeitig -- "online prediction requests per minute" (Kontingent, anpassbar)
    UND "online prediction tokens (input+output) per minute" = **Systemlimit
    800.000/min, NICHT anpassbar**.
  - Ein TTS-Call schlaegt auf BEIDE APIs zugleich (gleiche Anzahl+Latenz in beiden
    Zeilen -> ueber Agent Platform rein, ruft intern TTS-Engine).
- FOLGERUNG fuer Bündeln (mehrere Saetze pro Call):
  - Senkt REQUESTS -> hilft gegen die request-Wand (anpassbar).
  - Senkt NICHT die Token-Menge -> die fixe 800.000-Token/min-Decke bleibt.
    Bündeln verschiebt also nur von der request- zur token-Wand.
- ABER praktisch entspannt: Latenz ~12,5 s/Call, 0% Fehler -> mit der 4-s-Pause
  grob ~16-17 s/Satz -> ~5.000 Saetze/Tag. **"Ein Werk pro Tag" ist mit dem
  HEUTIGEN Setup realistisch**, noch ohne Bündeln. Die Token-Decke ist bei dem
  langsamen Takt real nicht die erste Wand.
- Forced-Alignment (Bloecke vertonen, Naehte per faster-whisper word_timestamps
  zuruecksuchen) waere der Weg, Bündeln auch fuer TAELLA (satzgenaues Alignment)
  nutzbar zu machen -> aber EIGENES Projekt, BOARD, nicht jetzt. Erster billiger
  Test waere "wie sauber sitzen die Naehte im natuerlichen Fluss".
